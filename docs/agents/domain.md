# Domain Docs

Before exploring, read `GLOSSARY.md` at the repo root and ADRs in `docs/adr/` that touch your area. Proceed silently if a file is absent.

Use the glossary's vocabulary in issue titles, test names, and specs (Grid, Cell, Piece, Tray, Clear, Element, Star, Power-up, Score, Combo, Game over). Avoid listed synonyms.

If your change contradicts an ADR, surface it explicitly: "Contradicts ADR-000X, reopening because…"
